### Post 1 — Vea, 2020-02-18

Some powers can stack with each other when cast by the same user, but in game tool tips aren't really helpful to determine which ones.

Many hands make light work so I was hoping we could have a list of what powers can stack from the same set.

I've attempted to make a list for the main buffs/debuffs from Corrupters/Defenders and dabbled in some other ATs. I've ignored most pure dps powersets/ATs as the secondary effects are negligible. The main goal for this would be to gain an understanding on whether or not it worthwhile recasting certain buffs/debuffs early and if stacking some powers via Burnout would be worth it.

Some validation of what I've put being accurate would also be welcome, as all information has been taken from City of Data and Paragon Wiki. (No access to the game at the time of writing)
