### Post 1 — Parabolus, 2026-09-11

**MELEE BENCHMARKS (DPS, CLEAR SPEED, PROC COMPARISONS)**

Game version: Issue 28, Page 4 (Open Beta)

Over the past six months, I have tested all 23 Brute melee sets for single-target DPS, clear speed and proc gains, plus Tanker single-target DPS for comparison. Results include individual benchmarks + combined Brute pylon/clear-speed time averages, including tier lists for both with procs and without procs. Testing was done on Open and Closed Beta.

What began as an update to @Ston's ST testing grew into a much bigger project. With all the builds, tests, attack chains and data, it's been a labour of love, and hopefully, a useful one. Big thanks to Ston, whose older melee tests inspired this project and who provided me with his 2026 Nerva mission and critter files for the clear speed testing!

• For clear speed tests: Knockback powers use an Overwhelming Force Dmg/KB→KD, replacing a Damage IO/proc (Full Procs) or the Dmg/End IO set pc. (No Procs).

**BUILDS **

All tests are using the same underlying build throughout, with the following fixed parameters:

**• Armour:** Willpower.

**• Accuracy / ToHit:** +30% global accuracy; +13% ToHit on Brutes / +16% on Tankers. All attacks meet the 95% hit-chance cap vs +3s.

**• Recharge:** +90% global; Hasten always used on cooldown with 2× L50+5 Recharge IOs.

**• Incarnates (T4):** Musculature Core, Ageless Core and Assault Radial. Ageless and Assault used on cooldown.

**• Interface:** Degenerative Core for pylons; Reactive Radial for clear speed.

**• Build Up / Rage:** 1× Gaussian’s Build Up proc only; Rage has +53% local recharge.

**• Slow resistance (-RechargeTime/-SpeedRunning debuff resistance):** 50%.

**• Excluded:** Force Feedback: +Recharge, Decimation: Build Up, inspirations and temporary powers.

Rage slotted with +53% local recharge to better reflect how it is typically slotted in a normal build.

**SINGLE-TARGET DPS TESTING**

Brute and Tanker pylon results are using the median defeat time from repeated runs, as follows:

**• Target:** MDC Vanguard Dummy; RWZ Vanguard Training Pylon for runs exceeding ten minutes.

**• Shared target stats:** 31,727.5 HP; 105.76 HP/s regeneration; 20% flat damage resistance.

**• Starting state:** 0 Fury on Brutes; 0 Rage stacks for Super Strength; no pre-stacked buffs/effects/etc.

**• Minimum runs per set (Full Procs / No −Res Procs / No Procs):** Brutes 10 / 5 / 3; Tankers 10 / 5 / 2.

**• Reported result:** Median defeat time.

DPS Formula: (31,727.5 ÷ defeat time in seconds + 105.76) ÷ 0.80

**CLEAR SPEED TESTING**

Ston’s 2026 Nerva Outdoor Clear Speed Test using custom enemies designed to approximate resistance averages seen in normal gameplay:

**• Difficulty:** +4×8 with AE Invincibility. Enemy debuffs (including -recharge and -damage) still apply.

**• Enemies:** Eight enemy mobs totalling 56 Minions, 16 Lieutenants, 15 Bosses and one Elite Boss.

**• Method:** Clear each mob before engaging the next. Athletic Run only; no other travel powers.

**• Starting state:** 0 Fury; 0 Rage Stacks for Super Strength; no pre-stacked buffs/effects/etc.

**• Minimum runs per set:** 10 Full Procs; 3 No Procs.

**• Reported result:** Median completion time.

Tankers omitted because making full use of their higher target caps and their Overcap damage requires grouping enemy mobs which is difficult to reliably reproduce between runs.
